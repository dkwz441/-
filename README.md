# Avito Monitor

Локальный монитор новых объявлений Avito. В окне задаются:

- ссылка на нужную категорию или готовую выдачу Avito;
- поисковая фраза;
- максимальная цена;
- интервал проверки.

Монитор открывает Avito через локальный Chromium, хранит профиль браузера только на компьютере и запоминает уже показанные объявления. Двойной клик по результату открывает его в браузере.

## Быстрый запуск в Windows

Установите Python 3.10 или новее, затем дважды щёлкните по `start_windows.bat`. При первом запуске он сам создаст окружение и установит браузер. В дальнейшем этот же файл сразу откроет меню программы.

## Установка

Нужен Python 3.10 или новее. В каталоге проекта выполните:

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m playwright install chromium
.venv\Scripts\python avito_monitor.py
```

Linux/macOS:

```bash
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python avito_monitor.py
```

## Использование

1. На Avito откройте нужный город и категорию, затем скопируйте адрес страницы в поле «Ссылка на категорию».
2. Укажите запрос и максимальную цену.
3. Оставьте видимый браузер включённым при первом запуске. Если Avito покажет проверку, монитор подождёт до 10 минут: пройдите её вручную, и работа продолжится автоматически.
4. Нажмите «Старт». Первое сканирование также покажет актуальные объявления; следующие — только новые.

## Автобронь

В блоке «Автобронь» можно независимо включить:

- отправку продавцу заданного сообщения;
- открытие оформления Авито Доставки;
- нажатие финальной кнопки заказа.

Для автоматического заказа нужно отдельно включить разрешение списания и указать лимит действий за один запуск. По умолчанию лимит равен одному. Скрипт использует вход, адрес и способ оплаты из локального профиля браузера и не сохраняет эти данные в своих файлах.

Если Avito просит войти, выбрать адрес, пройти капчу или подтвердить платёж через банк, это нужно сделать вручную в открывшемся браузере. Наличие кнопок покупки зависит от объявления, региона и настроек доставки продавца.

Минимальный интервал — 60 секунд. Практичное значение — 300–600 секунд. Скрипт не вводит логин, пароль или данные карты и не обходит проверки Avito.
