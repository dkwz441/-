# Avito Parts Hunter

Локальный монитор объявлений о компьютерных комплектующих на Avito. Работает через Brave и отдельный локальный профиль браузера.

## Возможности

- выбор города;
- выбор комплектующей: оперативная память, процессор, видеокарта, материнская плата, SSD, HDD, блок питания, охлаждение, корпус, платы расширения и другие детали;
- большой список производителей для каждого типа товара;
- ручной ввод любого отсутствующего производителя;
- свободный запрос вроде `оперативка Kingston 2x16 32gb` с автоматическим разбором;
- проверка типа товара, производителя и характеристик по заголовку объявления;
- автоматическое перелистывание до 20 страниц Avito за цикл;
- дополнительные слова поиска, максимальная цена и интервал;
- два независимых окна мониторинга с разными фильтрами;
- уведомления о новых объявлениях;
- сообщение продавцу, открытие доставки и автоматическое подтверждение заказа.

## Запуск в Windows

Нужны:

1. Python 3.12 с включённой опцией `Add python.exe to PATH`.
2. Установленный браузер Brave.

Распакуйте архив целиком и дважды щёлкните `start_windows.bat`. Первый запуск установит Python-зависимости, следующие запуски откроют программу сразу.

В первом окне нажмите `＋ ВТОРОЙ МОНИТОР`, чтобы одновременно запустить второй поиск. У каждого монитора отдельный профиль Brave, поэтому при первом запуске каждого окна нужно отдельно войти в Avito.

## Вход в Avito

Нажмите `Войти в Avito`, выполните обычный вход в открывшемся Brave и затем закройте окно браузера. Сессия и cookies останутся в локальном профиле этого монитора. При следующих запусках программа откроет Avito уже с сохранённым входом.

У двух мониторов разные профили Brave, поэтому вход выполняется по одному разу в каждом окне. Скрипт не записывает логин или пароль в свои файлы. Если Avito завершит сессию, повторите вход этой же кнопкой.

## Поиск

Выберите комплектующую и производителя. Если нужного бренда нет в списке, просто напечатайте его в поле «Производитель». Поле «Доп. слова» подходит для характеристик вроде `DDR5 32 ГБ`, `RTX 4070 Ti` или `850W Gold`.

Можно сразу написать весь запрос в поле «Умный запрос», например `оперативка 2x16 32gb`, и нажать `Распознать`. Программа сама выберет оперативную память и перенесёт `2x16 32gb` в характеристики. Включённый умный фильтр не покажет материнские платы и другие товары, которые Avito иногда подмешивает в выдачу. Поле «Страниц за цикл» задаёт глубину автоматического перелистывания.

Первое сканирование показывает текущие объявления, дальнейшие — новые. Минимальный интервал составляет 60 секунд; рекомендуемый — 300–600 секунд.

## Автобронь

Режимы можно включать независимо:

- отправить продавцу указанный текст;
- открыть оформление Авито Доставки;
- нажать финальную кнопку заказа.

Для автоматического заказа требуется отдельное разрешение списания и лимит действий. Скрипт использует данные, уже сохранённые в отдельном профиле Brave, и сам не хранит логины, пароли, адреса или реквизиты карты.

Вход, капча и подтверждение банка выполняются вручную. Доступность покупки и доставки зависит от конкретного объявления.
